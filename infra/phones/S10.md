# Samsung Galaxy S10 — the "ops phone"

**What it is:** 2019 flagship, 8 GB RAM, Exynos 9820 or Snapdragon 855 (arm64). Its last
Android is **12 (One UI 4.1)**, and security updates have ended.

**Its job:** stay on a charger as the always-on alert and backup-access phone. It runs
Tailscale, ntfy, Telegram and Termux. Keep banking and personal accounts on the newer phone.

Menu names below are from One UI 4.1. If yours differ slightly, use the Settings search (🔍).

## Step 1 — Update and tidy (10 min)

1. **Settings → Software update → Download and install.** Get the last One UI 4.1 build.
2. **Settings → Apps** → uninstall or disable anything you don't use (Samsung extras, old
   games). Less running means more RAM for Termux.
3. **Settings → Biometrics and security → Install unknown apps** → allow **Chrome** (or your
   browser) only while you install F-Droid in the next step. Turn it off again afterwards,
   and allow **F-Droid** instead.

## Step 2 — Install the apps

From [APPS.md](./APPS.md), S10 column ✅:
F-Droid → Obtainium → Termux, Termux:API, Termux:Widget, Termux:Styling → Tailscale →
Bitwarden → Aegis → ntfy → Telegram → Material Files → LocalSend.

## Step 3 — Stop Samsung killing the background apps (important)

Samsung's battery manager is aggressive. Without this, Tailscale, ntfy and Termux get put to
sleep and alerts stop arriving.

1. **Settings → Battery and device care → Battery → Background usage limits**
   - Turn **off** "Put unused apps to sleep".
   - **Never sleeping apps → +** → add **Termux, Termux:API, Tailscale, ntfy, Telegram**.
2. **Settings → Apps → Termux → Battery** → **Unrestricted**. Repeat for Tailscale and ntfy.
3. **Settings → Battery and device care → Battery → More battery settings** →
   **Adaptive battery: off** (optional, but it helps an always-on phone).
4. Open **Recent apps**, tap the Termux icon at the top of its card → **Keep open** (the lock).

## Step 4 — Android 12 "phantom process killer" fix (important)

Android 12 kills background processes started by apps like Termux (tmux, ssh, mosh). You
see `[Process completed (signal 9)]`. The S10 has **no settings switch** for this, so it
takes one ADB command. You can run it **from the S10 itself**, no computer needed:

1. **Settings → About phone → Software information** → tap **Build number** 7 times →
   Developer options are now on.
2. **Settings → Developer options → Wireless debugging → on.** Connect to Wi-Fi first.
3. Open **split screen**: Termux on one half, Settings → Developer options → Wireless
   debugging on the other. Tap **Pair device with pairing code**; it shows an IP:port and a
   6-digit code.
4. In Termux (`android-tools` was installed in TERMUX.md step 2):
   ```sh
   adb pair 192.168.x.x:PAIRPORT        # the pairing IP:port and 6-digit code from the dialog
   adb connect 192.168.x.x:PORT         # the IP:port shown on the main Wireless debugging screen
   adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"
   adb shell "/system/bin/device_config get activity_manager max_phantom_processes"   # should print 2147483647
   ```
5. Turn **Wireless debugging off** again when done.

Google Play Services can occasionally reset this. If Termux sessions start dying again,
repeat step 4. On Android 12 there's also a separate "excessive CPU" kill that no setting can
turn off, so avoid leaving heavy jobs running on the phone; run them on the server.

## Step 5 — Tailscale and alerts

1. **Tailscale** → sign in with the same account as your other phone and the server. You'll see
   `aurora-01`. In the app, set **Always-on VPN: on** (Android asks; allow it).
2. **ntfy** → **+ Subscribe** → server `https://ntfy.sh` (or your own ntfy URL once the
   monitoring stack's ntfy is set up), topic = the one Uptime Kuma posts to. Set its
   notification to **high priority** so it can wake the phone.
3. **Telegram** → open your Hermes bot → pin the chat.

## Step 6 — Termux + tmux

Follow [TERMUX.md](./TERMUX.md) steps 2–7. S10-specific notes:
- `ssh-keygen -C` will say `SM-G973F` (or similar), which labels this phone's key on the
  server.
- Put the **server-status** and **hermes-logs** widgets on the home screen: this phone's job
  is quick checks.

## Step 7 — Lock it down (it no longer gets security updates)

- **Settings → Biometrics and security → Secure Folder**: skip it; keep sensitive stuff off
  this phone instead.
- Use **Bitwarden with a PIN/biometric unlock** and set its vault timeout to 5 minutes.
- Don't sideload random APKs on it. F-Droid, Obtainium and Play only.
- If the phone is lost: remove its line from `~/.ssh/authorized_keys` on the server, remove
  the device in the [Tailscale admin](https://login.tailscale.com/admin/machines), and log it
  out of Telegram (Settings → Devices).
