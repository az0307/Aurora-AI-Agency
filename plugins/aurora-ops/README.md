# aurora-ops (Claude Code plugin)

Skills for running aurora-01. Enable via the marketplace in this repo:
```
/plugin marketplace add az0307/Aurora-AI-Agency
/plugin install aurora-ops@aurora
```
Or it's pre-listed in the repo's `.claude/settings.json`. Skills: `provision-box`, `stack-up`,
`box-health`, `spec-driven`. They follow the constitution in `.specify/memory/constitution.md`.

> Schemas here follow the documented plugin/skill shape; if `/plugin` reports a mismatch, your
> Claude Code version's schema has moved — check `/plugin` and the docs.
